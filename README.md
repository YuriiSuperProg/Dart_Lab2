# Dart Lab2 — ToDo приложение

Консольное ToDo-приложение на языке Dart. Позволяет добавлять, просматривать, отмечать выполненными и удалять задачи. Демонстрирует работу с классами, конструкторами, полями, методами, геттерами и статическими полями.

## Как запустить

1. Клонировать репозиторий:

```bash
    git clone https://github.com/YuriiSuperProg/Dart_Lab2
```

2. Перейти в папку проекта:

```bash
   cd lab2_todo
```

3. Установить зависимости:

```bash
    dart pub get
```

4. Запустить приложение:
```bash
    dart run
```

## Команды приложения

|Команда|Действие|
|-------|--------|
|`add`|Добавить задачу|
|`list`|Показать все задачи|
|`done`|Отметить задачу выполненной|
|`delete`|Удалить задачу|
|`exit`|Выйти из приложения|

## Ответы на вопросы

1. **В чём разница между полем класса и обычной переменной в функции?**

Поле класса принадлежит конкретному объекту (экземпляру) и существует, пока живёт объект. К нему можно обращаться из любого метода класса. Обычная переменная внутри функции существует только во время выполнения этой функции и недоступна извне. Поля описывают состояние объекта, а локальные переменные — временные данные для вычислений.

2. **Что такое конструктор и зачем он нужен?**

Конструктор — это специальный метод, который вызывается автоматически при создании объекта. Он нужен для инициализации полей объекта начальными значениями. Без конструктора пришлось бы создавать объект, а затем вручную присваивать каждому полю значение.

3. **Зачем нужен `@override` перед `toString()?` Что будет, если его убрать?**

`@override` — это аннотация, которая сообщает компилятору, что метод переопределяет метод родительского класса (`Object`). Она помогает поймать опечатки в имени метода. Если её убрать, код продолжит работать (переопределение всё равно произойдёт), но компилятор не будет проверять корректность сигнатуры, и при опечатке (например, `toStrng()`) вы не получите предупреждения — метод просто не переопределится.

4. **Чем статическое поле `static int _counter` отличается от обычного поля? Сколько копий этого поля существует в программе?**

Обычное поле существует в каждом экземпляре класса отдельно — у каждого объекта своё значение. Статическое поле принадлежит самому классу и существует в единственном экземпляре на всю программу. В программе существует одна копия статического поля `_counter`, независимо от количества созданных объектов `Todo`.

5. **Что означает нижнее подчёркивание в `_counter`?**

В Dart символ _ делает идентификатор приватным для файла (библиотеки), а не для класса, как в некоторых других языках. То есть `_counter` доступен только внутри файла `lib/todo.dart` и не виден из других файлов проекта. Это соглашение помогает скрыть внутреннюю реализацию класса от внешнего кода.
